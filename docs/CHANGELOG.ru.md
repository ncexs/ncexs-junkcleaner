## [v1.3] - 2025-07-10
### ✨ Добавлено
- 🧠 **Опция очистки ОЗУ** – Очистка памяти с помощью сборщика мусора PowerShell (спасибо [Ryzki Romadoni](https://www.youtube.com/@ryzprogm) за идею).
- 🧭 **Интерактивные запросы**:
  - `[Y/N]` Junk & Cache Cleaner (Очистка мусора и кэша)
  - `[Y/N]` Deep Cleanup (Глубокая очистка)
  - `[Y/N]` Antivirus Scan (Сканирование Windows Defender)
  - `[Y/N]` Clear RAM (Очистка оперативной памяти)

### 🔧 Улучшено
- 🌐 **Очистка кэша браузеров** – Объединена в эффективный цикл.
- 📄 **Вывод логов** – Добавлены чёткие заголовки разделов.

> [!WARNING]
> **Окончание поддержки (EOL)**: Эта версия отмечена как End of Life. Дальнейшие обновления и поддержка предоставляться не будут.

## [v1.2] - 2025-07-10
### ✨ Добавлено
- 🛡️ **Интеграция антивирусного сканирования** (Опционально):
  - Быстрое сканирование Windows Defender.
  - Автоматическое обнаружение Defender.
  - Полностью оффлайн (без скачивания файлов).
- 📄 **Улучшенный вывод логов** – Добавлены структурированные заголовки.
- 🔄 **Интерактивные запросы**:
  - Delete Recycle Bin? `[Y/N]`
  - Run antivirus scan? `[Y/N]`

### 🔧 Улучшено
- 🧹 **Очистка недавних файлов** – Удаляет только ярлыки `.lnk` (безопасно для панели быстрого доступа).
- 🌐 **Очистка кэша браузеров** – Объединена в единый цикл.
- 📦 **Консолидация скрипта** – Упрощено до одного `.bat` файла.

## [v1.1] - 2025-07-07
### ✨ Добавлено
- ✅ **Автоматический запрос прав** – Автоматический запрос прав администратора (UAC) при запуске.
- 🧹 **Расширенная очистка**:
  - `%TEMP%`
  - `C:\Windows\Temp`
  - `C:\Windows\Prefetch`
  - Недавние файлы (только `.lnk` – безопасно для панели быстрого доступа).
- 🌐 **Очистка кэша браузеров** – Поддержка Chrome, Edge, Brave, Vivaldi, Opera, Chromium и Firefox.
- 📄 **Создание логов** – Автоматическое создание файла `log_ncexs.txt`.

### 🔀 Варианты скрипта
- `ncexs-junkcleaner-v1.1.bat` – Полная очистка, включая корзину.
- `ncexs-junkcleaner-v1.1-nobin.bat` – Исключает корзину (безопасный режим).

## [v1.0] - 2025-07-07
### 🎉 Первый релиз
- ✅ **Очистка в один клик** – `.bat` скрипт для удаления мусорных файлов Windows.
- 🗑️ **Очистка Temp** – Удаляет `%TEMP%` и `C:\Windows\Temp`.
- 🧹 **Кэш приложений** – Очистка кэша популярных программ: NetBeans, Python, Adobe, VS Code.
- 🚀 **Оптимизация Prefetch** – Очистка папки предварительного запуска Windows.
- 🧼 **Интеграция Disk Cleanup** – Запуск встроенной утилиты `cleanmgr`.
- 🔒 **Автоматический запрос UAC** – Запрос прав администратора при запуске.
- 💡 **Простота и лёгкость** – Идеально для новичков: просто распакуйте и запустите.
- ⚠️ **Безопасность** – Не удаляет точки восстановления и личные файлы пользователя.
